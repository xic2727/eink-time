# 微雪2.13寸墨水屏时钟天气显示

## 文件说明

### clock_weather.py
完整版本，显示时钟和天气信息
- 显示日期和星期
- 显示实时时钟（局部刷新）
- 显示天气、温度、湿度及空气质量/风向
- 内置双源免费高可用天气 API（无需注册、免 Key，开箱即用，支持多源自动故障转移）
- 自动容灾缓存（遇到短暂网络波动自动保持上次有效天气，避免白屏报错）
- 每小时自动定时刷新天气信息

**依赖：**
```bash
pip install requests pillow
```

**运行：**
```bash
python clock_weather.py
```

### clock_simple.py
简化版本，只显示时钟
- 显示日期和星期
- 显示实时时钟（每秒局部刷新）
- 无需网络连接

**运行：**
```bash
python clock_simple.py
```

## 使用说明

1. 确保已安装微雪墨水屏驱动库
2. 确保 `lib` 和 `pic` 目录在正确位置
3. 运行程序后，按 Ctrl+C 可以安全退出

## 自定义配置

在 `clock_weather.py` 顶部的【用户配置】区域进行修改：

### 1. 修改城市
支持直接输入中文城市名（如 `"广州"`、`"北京"`、`"深圳"`、`"天河区"`）或9位天气城市代码（如 `"101280101"`）：
```python
CITY = "广州"  # 改成你的城市
```

### 2. 调整天气更新频率
修改 `WEATHER_UPDATE_INTERVAL`（单位：秒，默认 3600 秒即 1 小时）：
```python
WEATHER_UPDATE_INTERVAL = 3600
```

### 3. 可选：配置高德开放平台 Key
默认已内置免 Key 免费公共接口。如需使用官方高德开放平台接口（每天5000次免费额度），可在 [高德开放平台](https://lbs.amap.com) 免费申请 Web 服务 Key 并填入：
```python
AMAP_KEY = "你的高德WebServiceKey"  # 选填，留空则使用免Key公共接口
```
